# Novem-ever Yours — Parallax Edition

A separate experimental anniversary storytelling website. The original `-novem-ever-yours-` repository remains untouched.

## Direction
- Cinematic, scroll-led love story with layered parallax depth
- Winter editorial palette: ivory, muted blue, burgundy, soft Daisy details
- Mobile-first performance and accessible reduced-motion fallback
- Reuse existing public photo assets from the original site by URL for this first prototype; do not modify the original repository

## Local development
```bash
npm install
npm run dev
npm run build
```

## Status
Initial scaffold — visual and interaction QA still required before publication.

## GitHub Pages

This project is published from the production `dist/` output using the GitHub Actions Pages workflow. In repository Settings → Pages, keep the deployment source set to **GitHub Actions**.
